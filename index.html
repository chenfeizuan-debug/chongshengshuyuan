生成完怎么用

点上面按钮后文件会存进手机的「下载」或「文件」。接着二选一：

用「文件」App 分享到香色闺阁

1. 打开「文件」App，进「下载」或「Downloads」，找到 syiism聚合.已换key.xbs。

2. 长按这个文件 → 点共享（或右上角分享图标）。

3. 在 App 列表里选香色闺阁，它会自动导入。

4. 回到香色闺阁，书源列表里会出现 syiism聚合 等 3 个名字。

在香色闺阁里直接导入

1. 打开香色闺阁，进书源管理，找到导入。

2. 选择从文件导入，选中刚下载的 syiism聚合.已换key.xbs。

3. 导入成功后，列表里会出现 3 个书源：syiism聚合、syiism聚合听书、syiism聚合短剧。

这是同一份书源的四种媒体类型，小说、听书、漫画、短剧各占一个入口，四个都要留着。

常见问题

为什么非要自己的 key？

额度是按账号算的。用别人的 key，花的是别人的额度，对方随时能在面板里撤销，你就用不了了。

自己注册一个，额度归你，也不用担心哪天突然失效。

我的 key 会不会被传到服务器？

不会。整个替换过程只在这台设备的浏览器里完成，这个网页不对任何地方发请求，也没有后端。

你可以直接断网再用它——照样能生成。

提示「这个 key 看起来不对」怎么办？

检查是不是漏了开头三个字符 lp_，或者复制时多带了空格、引号、换行。

回到面板，在「API 密钥」那里点复制按钮重新拿一次。

下载没反应 / 点了没动静？

有些手机浏览器会拦下载。换成 Safari 或 Chrome 再试一次。

另外生成按钮下面那行绿框里就是完整文件名，也可以长按它选择下载。

之前有人给过我一个能用的书源，还需要这个吗？

那个里面写死的是发给你的人的 key，花的是他的额度，他一旦撤销或删除这把 key，你那边就会全线报错。

用这个页面换成你自己的，才算真正归属你。

全程在本机处理，无后端、无上报

本页面为纯静态文件，不含任何 API key。它做的事：把你的 key 写进书源模板的 22 处固定位置，再按香色闺阁的容器格式加密打包，产出可直接导入的 .xbs。
