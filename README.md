# 重生集合 1.7.1 · 书源生成器

一个纯静态网页。填上你自己的 API key，当场生成香色闺阁（StandarReader）书源文件。

**你的 key 只在你的手机上处理，不会上传到任何服务器。** 这个页面没有任何后端，
也不发起任何网络请求——你可以在浏览器的「网络」面板里亲眼验证这一点。

## 手机上怎么用

1. 用手机浏览器打开这个页面（网址见仓库 About 或你自己的部署地址）。
2. 把你自己的 API key 粘进去，点**生成书源文件**。
3. 下载到 `重生集合1.7.1.已换key.xbs`，长按 → 共享 → 选**香色闺阁**。

导入成功后，书源列表里会出现 4 个名字：

| 书源名 | 类型 | 平台数 |
| --- | --- | --- |
| 重生集合1.7.1 | 小说 | 26 |
| 重生集合听书1.7.1 | 听书 | 4 |
| 重生集合漫画1.7.1 | 漫画 | 3 |
| 重生集合短剧1.7.1 | 短剧 | 3 |

四个都要留着，它们是同一份书源的四种媒体类型，各占一个入口。

## 去哪弄 key

到书源服务的用户中心自己注册、登录，然后在「个人中心 → API 密钥」里创建一把。
**每人用自己那把，各自消耗各自的额度。**

## 为什么页面上没有内置 key

内置 key 的版本一旦那把 key 被撤销或额度耗尽，所有拿到文件的人会**同时**失效，
而且报错是「缺少鉴权凭证」，看起来像书源坏了。所以这里放的是**不含任何凭证**的
模板，key 由你在本地写进去。

  这是上游的时段限制，不是书源坏了。
