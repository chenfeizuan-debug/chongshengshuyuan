# 书源生成器 · 重生聚合v1.8.1 / syiism聚合v2.8.3

一个纯静态网页。**两份聚合书源都能生成**，进去先在页顶两个按钮里选一份，
再填你自己的 API key，当场得到香色闺阁（StandarReader）书源文件。

**你的 key 只在你的手机上处理，不会上传到任何服务器。** 这个页面没有任何后端，
也不发起任何网络请求——你可以在浏览器的「网络」面板里亲眼验证这一点。

## 两份书源，选一个

| | 重生聚合v1.8.1 | syiism聚合v2.8.3 |
| --- | --- | --- |
| 网站 | chongsheng.dpdns.org | loomproxy.dpdns.org |
| 能不能注册 | **不能**（已停止） | **能** |
| 书源别名 | 4 个 | 3 个 |
| 平台 / 数据源 | 约 36 个 | 15 个 |
| 漫画 | 有 | 没有 |
| 夜间时段限制 | 有（22:00–05:00） | 无 |

**两站的 key 不通用**，选错站会提示鉴权失败。
没有 重生聚合v1.8.1 账号就用 syiism聚合v2.8.3 那份。

## 手机上怎么用

1. 用手机浏览器打开这个页面。
2. **先在页顶选一份**（重生聚合v1.8.1 / syiism聚合v2.8.3），
   再把你自己的 API key 粘进去。
3. 点**生成书源文件**，下载到 `syiism聚合v2.8.3.已换key.json`。
   页面默认生成**`.json`（通用格式）**；如果你在用香色闺阁，
   在格式按钮里切到 `.xbs` 再生成，文件名就是 `syiism聚合v2.8.3.已换key.xbs`。
4. 长按下载好的文件 → **共享** → 选**香色闺阁**（xbs）
   或任意阅读软件（json）。

页面上有两个便利设计：

- **key 按份记忆**：每一份各存各的，切走再切回来还在，不用重打；第一次切过去是空的。
- **清除按钮**：点一下把当前这份的输入框和存档一起清空，换人用或填错重来都方便。

导入成功后，书源列表里会出现：

| 书源 | 书源名 | 个数 |
| --- | --- | --- |
| 重生聚合v1.8.1 | 重生聚合v1.8.1、重生聚合听书v1.8.1、重生聚合漫画v1.8.1、重生聚合短剧v1.8.1 | 4 |
| syiism聚合v2.8.3 | syiism聚合v2.8.3、syiism聚合听书v2.8.3、syiism聚合短剧v2.8.3 | 3 |

同一份书源的几种媒体类型各占一个入口，都要留着。

## 去哪弄 key

两个站的面板路径一样，都是 **个人中心 → API 密钥 → 创建密钥**：

- syiism聚合v2.8.3 `https://loomproxy.dpdns.org/panel/login` —— **注册开放**，点「注册新用户」即可。
- 重生聚合v1.8.1 `https://chongsheng.dpdns.org/panel/login` —— **已停止注册**，只有以前注册过的账号才有 key。

**每人用自己那把，各自消耗各自的额度。**

## 为什么页面上没有内置 key

内置 key 的版本一旦那把 key 被撤销或额度耗尽，所有拿到文件的人会**同时**失效，
而且报错是「缺少鉴权凭证」，看起来像书源坏了。所以这里放的是**不含任何凭证**的
模板，key 由你在本地写进去。
