# 书源生成器 · 重生聚合v1.8.1 / syiism聚合v3.1.0

一个纯静态网页。**两份聚合书源都能生成**，进去先在页顶两个按钮里选一份，
再填你自己的 API key，当场得到书源文件。

生成前先选格式：**`.xbs`（默认，给香色闺阁）** 或 **`.json`（给轻悦时光）**。

> `.xbs` 和 `.json` 是**两种软件各自的格式**，不是同一样东西换个扩展名。
> `.json` 输出的是轻悦时光的 Legado 结构，key 写在源里的变量上
> （重生聚合v1.8.1 用 `APIKey`，syiism聚合v3.1.0 用 `apikey`）。
> 拿 `.xbs` 去轻悦时光导入会提示「未解析到书源」。

**你的 key 只在你的手机上处理，不会上传到任何服务器。** 这个页面没有任何后端，
也不发起任何网络请求——你可以在浏览器的「网络」面板里亲眼验证这一点。

## 两份书源，选一个

| | 重生聚合v1.8.1 | syiism聚合v3.1.0 |
| --- | --- | --- |
| 网站 | chongsheng.dpdns.org | loomproxy.dpdns.org |
| 能不能注册 | **不能**（已停止） | **能** |
| 书源别名 | 4 个 | 4 个 |
| 平台 / 数据源 | 约 36 个 | 约 37 个 |
| 漫画 | 有 | 有 |
| 夜间时段限制 | 有（22:00–05:00） | 无 |

**两站的 key 不通用**，选错站会提示鉴权失败。
没有 重生聚合v1.8.1 账号就用 syiism聚合v3.1.0 那份。

两份都是**四块结构**：导入香色闺阁后会自己分成**小说、听书、漫画、短剧**
四个分区，各管各的。所以一份文件里有四个别名，不是四个文件。

## 手机上怎么用

1. 用手机浏览器打开这个页面。
2. **先在页顶选一份**（重生聚合v1.8.1 / syiism聚合v3.1.0），
   再把你自己的 API key 粘进去。
3. 点**生成书源文件**，下载到 `syiism聚合v3.1.0.已换key.xbs`。
   页面默认就是 **`.xbs`（给香色闺阁）**；如果你在用**轻悦时光**，
   在格式按钮里切到 `.json` 再生成，文件名就是 `syiism聚合v3.1.0.已换key.json`。
4. 长按下载好的文件 → **共享** → 选**香色闺阁**（.xbs）
   或在**轻悦时光**里走 书源管理 → 导入，选那个 `.json`。

**两种格式别弄混：** `.xbs` 只给香色闺阁，`.json` 只给轻悦时光。
拿 `.xbs` 去轻悦时光导入会提示「未解析到书源」—— 那是格式不对，不是文件坏了，
回到页面切到 `.json` 重新生成一次就行。

页面上有两个便利设计：

- **key 按份记忆**：每一份各存各的，切走再切回来还在，不用重打；第一次切过去是空的。
- **清除按钮**：点一下把当前这份的输入框和存档一起清空，换人用或填错重来都方便。

导入成功后，书源列表里会出现：

| 书源 | 书源名 | 个数 |
| --- | --- | --- |
| 重生聚合v1.8.1 | 重生聚合v1.8.1、重生聚合听书v1.8.1、重生聚合漫画v1.8.1、重生聚合短剧v1.8.1 | 4 |
| syiism聚合v3.1.0 | syiism聚合v3.1.0、syiism聚合v3.1.0听书、syiism聚合v3.1.0漫画、syiism聚合v3.1.0短剧 | 4 |

同一份书源的几种媒体类型各占一个入口，都要留着；缺一个就少一块内容。

> 两站的别名命名习惯不同，别以为是写错了：
> 重生聚合是**品牌 + 类型 + 版本**（`重生聚合听书v1.8.1`），
> syiism聚合是**品牌 + 版本 + 类型**（`syiism聚合v3.1.0听书`）。

## 去哪弄 key

两个站的面板路径一样，都是 **个人中心 → API 密钥 → 创建密钥**：

- syiism聚合v3.1.0 `https://loomproxy.dpdns.org/panel/login` —— **注册开放**，点「注册新用户」即可。
- 重生聚合v1.8.1 `https://chongsheng.dpdns.org/panel/login` —— **已停止注册**，只有以前注册过的账号才有 key。

**每人用自己那把，各自消耗各自的额度。**

## 为什么页面上没有内置 key

内置 key 的版本一旦那把 key 被撤销或额度耗尽，所有拿到文件的人会**同时**失效，
而且报错是「缺少鉴权凭证」，看起来像书源坏了。所以这里放的是**不含任何凭证**的
模板，key 由你在本地写进去。

- 短剧/漫剧与听书的「正文」是媒体直链，不是文字，这是正常的。
- 重生聚合v1.8.1：塔读、书旗的目录第一行是「卷标题」，点了没反应，属正常。

  **小说** 565 项（番茄 13 + 话本/有度/得奇/米读/淘小说/猫眼/连尚/阅友/
  得间/塔读/爱丽丝/幻梦/微点/七猫/UXX/AcFun 等）；
  **听书** 218 项（番茄听书 163 + 骚麦 54 + AcFun 有声 1）；
  **漫画** 26 项（番茄 13 + AcFun 漫画 13）；
  **短剧** 98 项（红果短剧 21 + 红果漫剧 20 + AcFun 动漫/视频/短视频/里番 57）。
  纸间、QQ阅读落幕没有发现页接口，但**搜索能搜到**，不影响看书。
- 额度按平台独立计算，每日零点重置。
